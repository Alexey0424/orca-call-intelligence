{# Live resource curves — Task-Manager-style scrolling line graphs for GPU / VRAM / CPU / RAM. Rendered ONCE in status.html, OUTSIDE the 2s HTMX-swapped control-panel div, so its client-side history survives. Polls /resources.json (~1s adaptive) and redraws four es. GPU is whole-card only (single line). VRAM/CPU/RAM draw two bands: the ser-api share (rel, solid accent fill) under the whole-box line (glob) — the gap between them = everything else (Ollama/OS). Scope, honestly: GPU + VRAM are the WHOLE physical card (NVML / torch — every process on the GPU). CPU + RAM come from psutil INSIDE the container, which reads the un-namespaced WSL2 /proc, so they cover the whole WSL2 Linux VM (all containers + Linux OS) — NOT Windows-native processes, and RAM % is of the WSL2 memory allocation, not physical RAM. Hence the per-graph scope captions + the RAM used/total GB readout. #}
